# คู่มือใช้งาน

## การใช้งานทั่วไป

- **ค้นหา:** กดช่องค้นหาด้านบน หรือกด ⌘K (Ctrl+K บน Windows) เพื่อค้นหาเจ้าของบัญชี เมล บัญชี Page และเปิดหน้าต่าง ๆ
- **โหมดมืด:** กดปุ่มรูปพระจันทร์ด้านบน ระบบจำค่าที่เลือกไว้ในเบราว์เซอร์นั้น ถ้ายังไม่เคยเลือกจะใช้ตามเครื่อง
- **หน้าภาพรวม:** เริ่มจาก “ต้องจัดการวันนี้” กราฟค่าคอมมิชชันใช้ยอดที่นำเข้าจากไฟล์ CSV และไม่รวมคำสั่งซื้อที่ยกเลิก

## ขั้นตอนหลัก

1. **เพิ่มเจ้าของบัญชี** ที่หน้า “เจ้าของบัญชี” ระบบจะสร้าง Checklist ของ Shopee Affiliate และ Facebook Page ให้ทันที โดยกำหนดส่งใน 7 วัน
2. **เพิ่มเมล** ที่หน้า “เมล” ให้เก็บรหัสผ่านใน Bitwarden หรือ 1Password แล้วใส่เฉพาะลิงก์ไปยังรายการนั้น
3. **สมัครตาม Checklist** กดปุ่มเปิดหน้าและคัดลอกข้อมูล เจ้าของบัญชีกรอก ยืนยันตัวตน และยอมรับเงื่อนไขเอง จากนั้นกด “เสร็จแล้ว”
4. **บันทึกบัญชี** ที่หน้า “บัญชีแพลตฟอร์ม” แล้วเลือกเมลที่ใช้สมัคร เพื่อให้ระบบจับคู่อีเมลผลการสมัครได้
5. **เชื่อม Gmail** ที่หน้า “การเชื่อมต่อ” เพื่อให้ระบบช่วยตามผล

## ติดตามผลจากอีเมล

ระบบอ่านผู้ส่ง หัวข้อ และวันที่ของอีเมลจาก Shopee และ Facebook ทุก 5 นาที โดยไม่อ่านเนื้อหาอีเมล

ระบบเปลี่ยนสถานะเองเมื่อผ่านทุกข้อนี้ และบันทึกในประวัติว่า “ระบบ” เป็นผู้เปลี่ยน

- ผู้ส่งเป็นโดเมนที่รู้จัก และยืนยันผู้ส่งผ่าน
- หัวข้อระบุผลชัดเจน และพูดถึง Affiliate หรือ Page
- เมลนั้นผูกกับบัญชีบนแพลตฟอร์มนั้นเพียงบัญชีเดียว
- อีเมลใหม่กว่าสถานะปัจจุบัน

กรณีอื่นจะเข้าหน้า “อีเมลรอตรวจ” ให้คุณเลือกเอง กฎหัวข้ออีเมลเขียนจากการคาดการณ์ ควรเทียบกับอีเมลจริงในช่วงแรก

## Page Kit

เลือกเจ้าของบัญชี ใส่หมวดสินค้า แล้วกด “ร่างด้วย Claude” ระบบจะร่างชื่อ Page คำอธิบาย และโพสต์แรก ควรตรวจข้อความก่อนใช้ การร่างแต่ละครั้งมีค่าใช้จ่าย Claude API

## โพสต์ลง Facebook Page

1. ผู้ดูแลระบบเชื่อมบัญชี Meta แล้วจับคู่ Page ที่หน้า “การเชื่อมต่อ”
2. เพิ่มงานที่หน้า “คอนเทนต์” แล้วให้ผู้ดูแลระบบกดอนุมัติ
3. กด “ตั้งเวลา” แล้วเลือก Page และเวลา
4. ติดตามที่หน้า “คิวโพสต์” ซึ่งกรองตาม Page และสลับเป็นมุมมองปฏิทินได้

ถ้าแก้ข้อความที่อนุมัติแล้ว ต้องอนุมัติใหม่ และโพสต์ที่ตั้งเวลาไว้จะไม่ขึ้นจนกว่าจะตั้งใหม่

| สถานะ | ความหมาย | สิ่งที่ต้องทำ |
|---|---|---|
| รอโพสต์ | รอถึงเวลา | ไม่ต้องทำอะไร หรือกดยกเลิก |
| ล้มเหลว | Meta ปฏิเสธ หรือสิทธิ์หมดอายุ | อ่านสาเหตุ แก้ไข แล้วกดลองใหม่ |
| ต้องตรวจ Page | ไม่รู้ว่าโพสต์ขึ้นหรือยัง เช่น เครือข่ายขาดกลางทาง | เปิดดูที่ Page แล้วกด “ขึ้นแล้ว” หรือ “ยังไม่ขึ้น โพสต์ใหม่” |

ระบบไม่ลองโพสต์ซ้ำเองเมื่อไม่แน่ใจผล เพื่อกันโพสต์ซ้ำ จะลองใหม่เองเฉพาะกรณีติด rate limit

## Report ยอด Shopee

1. ตั้ง **Sub ID** ของแต่ละ Page ที่หน้า “Page” ให้ตรงกับค่าที่ใช้สร้างลิงก์ Shopee
2. ดาวน์โหลด report จาก Shopee Affiliate แล้วอัปโหลดที่หน้า “Report”
3. ตรวจว่าแต่ละช่องตรงกับคอลัมน์ในไฟล์ แล้วกด “นำเข้า”

- นำเข้าไฟล์เดิมซ้ำได้ ยอดจะไม่เพิ่ม และคำสั่งซื้อที่สถานะเปลี่ยนจะถูกอัปเดต
- ควรเลือกคอลัมน์รหัสสินค้าด้วย ไม่เช่นนั้นคำสั่งซื้อที่มีหลายสินค้าจะนับเป็นรายการเดียว
- ยอดที่จับคู่ Page ไม่ได้จะแสดงแยก เมื่อตั้ง Sub ID ภายหลัง ยอดจะเข้า Page นั้นเอง
- ยอดรวมไม่นับคำสั่งซื้อที่สถานะมีคำว่า `cancel` หรือ `ยกเลิก` แต่รวมรายการที่ยังรอยืนยัน จึงอาจไม่เท่ากับยอดที่ได้รับจริง

## การแจ้งเตือน

หน้า “การแจ้งเตือน” แสดงโพสต์ที่มีปัญหา การเชื่อมต่อที่หมดอายุ และสรุปประจำวันเวลา 08:00 น. ส่งออกไป Slack หรือ Discord ได้ถ้าตั้ง `NOTIFY_WEBHOOK_URL`
